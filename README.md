# Installation
1. Install [News++](https://github.com/Dr-Sauce/NewsPlusPlus/releases/latest). (Click iCloud link to install)
2. Install [wBlock](https://apps.apple.com/app/id6746388723) Safari extension. (Supports iOS 15.4+, macOS 12.3+)
3. Launch **wBlock** and follow the steps. Make sure to enable `Bypass Paywalls Clean Filter` during the setup.
4. Open **Control Centre** by swiping down the top right corner. Press **+**, add a Shortcuts button, and set it to **News++**.

# Usage
1. Launch **Apple News** app. Click on a article which required News+ subscription.
2. Open Control Centre and click **News++**. Wait for article to open in Safari.
3. Enjoy.

# FAQ
**- Can I use News++ with Chrome, Firefox?**
  
  Chrome, Firefox does not have extension support on iOS. If you want, you can install [Bypass Paywalls Clean for Firefox](https://gitflic.ru/project/magnolia1234/bypass-paywalls-firefox-clean) on [Reynard Browser](https://github.com/minh-ton/reynard-browser). (Needs to be sideloaded via [AltStore](https://altstore.io/), [TrollStore](https://ios.cfw.guide/installing-trollstore/) etc..)

**- Why Safari, not webview?**

  Webview provides great UX by allowing users to easily go back to their previous screen, but doesn't allow extensions to run.
